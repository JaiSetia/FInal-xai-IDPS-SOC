# IDPS final year project

## Model routing (who cooks what)
- Search, lookups, renames, boilerplate → code-searcher subagent (Haiku 5.5, low)
- Build a planned feature → implementer subagent (Sonnet 5.5, medium)
- Tests → test-runner subagent (Sonnet 5.5, low)
- UI, auth & payments, hard bugs → this session on Opus 5.5 (xhigh for auth & payments; max only when stuck)
- Plans and security audits → Fable 5.1 (/model fable; high, xhigh for audits)
- Code review → reviewer subagent (Opus 5.5, high). Never review with the model that wrote the code.
